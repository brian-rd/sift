# Sift 1.0.0 Beta 1

The first public beta of Sift: a lightweight, keyboard-first Windows Downloads organiser.

## Highlights

- One-file-at-a-time sifting with rebindable keyboard shortcuts.
- Keep, Trash, Undo, and File Away actions with immediate auto-advance.
- Suggested and pinned destinations, including quick destination selection.
- Safe staged Trash review or optional direct Windows Recycle Bin mode.
- History restoration for matching Recycle Bin items.
- Image, video, audio, PDF, text, and Markdown previews.
- Local sorting rules with a dry-run preview before files move.
- System, light, and dark themes.
- Local-only operation with no account, telemetry, or uploads.

## Install

1. Download `Sift_1.0.0-beta.1_x64-setup.exe` below.
2. Run the installer.
3. Choose the folder Sift should watch and start sifting.

The installer is currently unsigned. Windows SmartScreen may display an “unknown publisher” warning.

## Beta notes

- Windows x64 only.
- History displayed in the app currently covers the active session.
- Recycle Bin restoration requires the exact item to remain in the Recycle Bin and its original path to be available.
- Please report reproducible problems through [GitHub Issues](https://github.com/brian-rd/sift/issues).
