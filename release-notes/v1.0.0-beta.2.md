# Sift 1.0.0 Beta 2

This beta adds exact duplicate cleanup and polishes Sift's Windows integration.

## Highlights

- Finds byte-for-byte duplicate files using local SHA-256 comparisons.
- Recommends keeping the original file and selects generated copies such as `(1)`, `(2)`, and `- Copy` for removal.
- Reviews duplicate choices before moving anything to Sift Trash.
- Shows normal Windows paths without the `\\?\` prefix.
- Opens File Explorer with the selected file highlighted.
- Disables the embedded browser's default context menu while preserving Sift's own Trash actions.

## Install

1. Download `Sift_1.0.0-beta.2_x64-setup.exe` below.
2. Run the installer.
3. Choose the folder Sift should watch and start sifting.

The installer is currently unsigned. Windows SmartScreen may display an “unknown publisher” warning.

## Beta notes

- Windows x64 only.
- Duplicate comparison happens entirely on the device; files and hashes are not uploaded.
- Files selected during duplicate cleanup are staged in Sift Trash for review before recycling.
- Please report reproducible problems through [GitHub Issues](https://github.com/brian-rd/sift/issues).
